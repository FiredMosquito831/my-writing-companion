# Scene Card — <scene title or slug>

Fill every field while planning a scene (outline stage or rewrite diagnosis). Nine fields; a scene that cannot fill Event, Conflict, and Value charge is usually not a scene yet.

| Field | Entry |
|---|---|
| **Characters** | <who is present in-scene — chapter `characters:`, never `mentions:`> |
| **Place** | <where, with one concrete anchor detail> |
| **Time** | <when; clock reading if the thread has one> |
| **Event** | <what happens — the irreversible action of the scene> |
| **Conflict** | <what opposes it — a person, an obstacle, or something inside the character> |
| **Story value** | <the charged pair in play, e.g. trust/betrayal, safety/danger, belonging/exile> |
| **Value charge** | <state at scene start → state at scene end; flat if unchanged> |
| **Mood** | <the feeling the reader should carry out> |
| **Outcome** | <yes-but / no-and; what it costs, what it sets up> |

Guidance: a scene turns at least one value charge. If the charge is unchanged and no decision lands, the scene is a candidate for cutting or merging — a flat scene is usually a missing disaster or a skipped sequel (see `creative-writing-craft` scene-and-sequel resource when present). Attach the card to the beat it serves in `work/outline/chapter-NN.md`; project-setup copies this template into the author's project for planning use.
