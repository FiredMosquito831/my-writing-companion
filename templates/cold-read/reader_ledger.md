# Cold Read — Rolling Ledger

> The reader's accumulated memory, persisted to disk. This file is what makes a multi-sitting read behave like one continuous reader: every sitting reloads it, every batch updates it. **A stale ledger is an amnesiac reader.**
>
> Seed the marked sections BEFORE reading a word. Update EVERY section at the end of every batch (the muse agent persists; `@cold-reader` proposes the deltas). Delete guidance blockquotes when done.

_[Book Title]_ — single-reader cover-to-cover cold read.
_Assessment only. Nothing in `manuscript/` is modified. All output → `work/cold-reads/<YYYY-MM>/`._
_Every sitting begins: re-read the charter + this ledger + last ~40 lines of `issues.md`, then continue from `NEXT:`._

## Promise register (open promises — HOT / WARM / COLD)

> Number every promise (P1, P2...) and sort by heat. HOT = the reader is actively leaning forward; WARM = remembered when prompted; COLD = long-fuse. Promises move between tiers as the book works them. A promise that never pays is a finding; a payoff that arrives unearned is a finding too. Cross-check ids with `kb/promises/`.

**HOT:** _P1 [promise] · P2 [promise]_
**WARM:** _P10 [promise]_
**COLD (long-fuse):** _P20 [promise]_
