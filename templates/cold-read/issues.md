# Issues Log — The Cold Read (append-only)

> One line per issue, fixed format, append-only. **Never edit or delete a logged line** — if an issue is fixed or superseded, append a note. The last ~40 lines of this file are part of every sitting's resume context, and the final ranked issue list is generated from it, so the format must stay exact.

Format: `CR-### | ch:line | SEV | CAT | "quote" | why / reader-moment | fix direction | LINE/SCENE/STRUCT/META`
SEV: BLOCKER / MAJOR / MODERATE / MINOR. CAT: CONT, CANON, VOICE, CRAFT, STRUCT, PACE, REPEAT, META.

## Legend

| Severity | Meaning |
|---|---|
| **BLOCKER** | Breaks trust in the text: on-page contradiction, timeline impossibility, duplicated sentence, knowledge from nowhere, wrong object/name/fact |
| **MAJOR** | Hard stumble — reader re-reads or skims: off-voice dialogue, exposition dump, unearned reveal, re-explanation of a registered fact, hindsight leak |
| **MODERATE** | Noticed, forgiven once, not thrice: repeated scene-shape/image (log with counts), pacing sag, formulaic opening, hedge cluster |
| **MINOR** | Polish: word tics, metadata errors |

| Category | Meaning |
|---|---|
| `CONT` | Continuity — contradicts an earlier page, the ledger, or itself |
| `CANON` | Conflicts with locked canon decisions or source material |
| `VOICE` | Character or narrator voice break |
| `CRAFT` | Show-then-tell family: explaining the image, naming the emotion, theme stated directly |
| `STRUCT` | Chapter/arc architecture: duplicated beats, misplaced scenes, seam failures |
| `PACE` | Sags, rushes, over-extension |
| `REPEAT` | Repeated images, phrases, scene-shapes — always log counts |
| `META` | Files, titles, numbering, front-matter — not prose |

Final field = fix scope: `LINE` (one sentence) / `SCENE` (one scene) / `STRUCT` (crosses chapters) / `META` (files/metadata).

> Guidance:
> - The "why / reader-moment" field is mandatory — name the moment ("flipped back to check", "skimmed to the scene break"). No reader-moment, no issue.
> - "Fix direction" is a direction, not a patch. Prefer subtraction.
> - If an AUTO-FIX was applied (per the charter's autonomy tier), append `| FIXED: [what was done]` to the line's note rather than editing history.
> - Number continuously across batches. Never reuse an ID.
